Research Brief / 01

From Model to Agent: The Harness Stack

A capable model does not automatically become a useful Agent. The missing layer is Harness: runtime, tools, memory, skills, control, eval, UX, and feedback loops.

Failure Modes First

Harness exists because most Agent product failures happen between model capability and real workflow reliability.

Agents lose continuity across sessions and tools.

Multi-agent systems become role-playing pipelines with lossy handoffs.

Prompt rules do not create deterministic control.

Tool and skill ecosystems introduce supply-chain risk.

Evaluation often checks outputs, not whether user goals were actually satisfied.

Real workflows require integration, permissions, auditability, and domain context.
