Research Brief / 01

From Model to Agent: The Harness Stack

一个强模型不会自动变成有用的 Agent。缺失的是 Harness：runtime、tools、memory、 skills、control、eval、UX 和 feedback loops。

先看失败模式

Agent 产品的关键失败，通常发生在模型能力和真实 workflow 之间。

Agent 跨 session 和工具后失去连续性。

多 Agent 系统变成角色扮演流水线，交接不断压缩上下文。

prompt 规则无法形成确定性控制。

工具和 skill 生态带来供应链风险。

eval 经常只看输出，不看是否真正满足目标。

真实 workflow 需要集成、权限、审计和领域上下文。
