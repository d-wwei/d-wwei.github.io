Case File / Harness Evidence

SkillScanner

面向 skill、MCP 和 prompt-level supply-chain risk 的可移植安全扫描案例。

Security / Skills case-study GitHub repo

Problem

Agent skills 和 MCP tools 会带来新的供应链风险：隐藏指令、tool poisoning、数据外传、编码混淆、metadata poisoning 和 memory/state poisoning。

Why It Matters

skill 生态会像包生态一样扩散，但攻击面不只是代码，也可能是 prompt、工具描述、MCP payload 或文档伪装。

Product Thesis

Scanner 本身也可以是 skill。如果 Agent host 能读取 SKILL.md，安全能力就可以通过 instruction protocol 分发。

My Role / Judgment

核心判断是优先 portability，而不是依赖深度。一个需要大模型下载或复杂环境的 scanner，很难保护轻量 Agent workflow。

Architecture

SkillScanner 是一个 SKILL.md 加 reference files。

五层协议：

  1. Normalize。
  2. Pattern match。
  3. Semantic intent / archetype analysis。
  4. Context judge。
  5. Bucket-weighted verdict。

三道 gate：input、tool-result、output。

Design Tradeoffs

我选择 pure-instruction、zero dependencies。代价是扫描质量依赖 host Agent 的推理能力，因此协议必须足够结构化。

What I Built

  • 单文件 skill scanner。
  • scan protocol、threat catalog、attack cases、report templates、self-test。
  • 10 类 threat category。
  • 3-gate scanning architecture。
  • 5-layer protocol 和 bucket-weighted scoring。
  • EN/ZH 双语支持。

Evidence

公开 repo 描述了 universal AI agent skill security scanner、zero dependencies、bilingual EN/ZH、5-layer protocol、3-gate architecture 和 OWASP LLM Top 10 tags。

What I Learned

Agent supply-chain security 需要理解 intent，而不只是匹配 syntax。

Status

Prototype / portable scanner。

Next

下一步是和 agent-guard 这类 runtime control 层连接，增加 corpus-level evaluation，并形成 skill 安装、更新、拒绝的治理流程。
